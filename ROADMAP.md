# Roadmap

Evra is stable: 1.0 was its first stable release, and its file format is at version 1. What changed in each version is
in the [changelog](CHANGELOG.md).

## Next

- **Sub-timelines.** Timelines linked into a tree, like continent › nation › city, or universe › galaxy › planet, and
  a timeline branched for an alternate history. Parent events will show as context in the timelines below them, and
  important events will rise into the timelines above.

  Version 1 of the [file format](docs/dev/file-format.md) already reserves the fields this needs, so your timelines
  won't need converting.
