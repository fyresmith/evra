# Keyboard and mouse

Shortcuts work while a timeline has focus. Click the timeline first if another pane has focus. Press **?** in a timeline to see this list there.

## Mouse

| Action | Result |
|---|---|
| Double-click a card | Edit it (a linked card opens its note) |
| Double-click empty space | Add an event at the nearest year, on that side |
| Double-click a group card | Spread its events out |
| Drag along the line | Select a stretch of time, then choose **New era** or **New span** |
| Drag a card | Change its date; drag it across the line to switch sides |
| Drag a dot | Pull a moment out into a span, or move either end of a span |
| Drag an era edge | Resize the era, from anywhere across the timeline; hold **Alt** to split a shared edge |
| Drag empty space | Pan |
| Shift + click | Add a card to the selection, or remove it |
| Shift + drag | Draw a selection box |
| Right-click a card | Card options |
| Right-click empty space | Add an event, span or era; set "now"; paste; fit an era to the screen |
| Right-click an era label | Fit that era to the screen |
| Scroll | Move through time |
| Shift + scroll | Scroll across, when cards overflow |
| Ctrl/⌘ + scroll, or pinch | Zoom |
| Alt while dragging | Move by single days instead of snapping |

On touch screens, press and hold empty space for the right-click menu.

## Keyboard

| Keys | Action |
|---|---|
| Ctrl/⌘ K or / | Search cards, eras and notes, or type a date |
| Ctrl/⌘ P | Obsidian's command palette, with every Evra command |
| N | New event at the pointer |
| E or ↵ | Edit the selected card |
| ↵ (in a description) | Save, and start the next event |
| Esc | Stop editing; close a menu; clear the selection |
| J / K | Select the next or previous card in time |
| S | Make the selected card a span, or a single moment again |
| L | Open the selected card's options |
| 1–9 | Color the selection with a preset |
| 0 | Clear the color |
| ↑ ↓ (vertical) or ← → (horizontal) | Nudge the selection by one ruler mark (Alt: by one day) |
| ← → (vertical) or ↑ ↓ (horizontal) | Move the selection to one side or the other |
| Ctrl/⌘ C / V / D | Copy / paste at the pointer / duplicate |
| Ctrl/⌘ A | Select all cards |
| ⌫ or Delete | Delete the selection |
| Ctrl/⌘ Z | Undo |
| Ctrl/⌘ Shift Z, or Ctrl Y | Redo |
| G | Go to a date |
| F | Fit everything |
| Z | Zoom to the selection |
| + / − | Zoom in / out |
| . | Go to "now" |
| B | Saved views |
| ? | Show the shortcuts |
